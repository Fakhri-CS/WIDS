# WIDS PCAP test fixtures

This directory is for committed, sanitized, deterministic PCAP/PCAPNG fixtures
only. It must never contain private production captures.

`lab_management_frames.pcap` is generated by `generate_samples.py` and uses
placeholder MAC addresses. It contains:

1. WPA2 beacon for `WIDS-Lab` on channel 6
2. Wildcard probe request
3. Open-system authentication request
4. Deauthentication frame with reason code 7
5. Disassociation frame with reason code 8

Regenerate it with:

```bash
python pcap_samples/generate_samples.py
```

Live evidence belongs under `runtime/pcap/`, not here.
